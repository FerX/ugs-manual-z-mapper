# Mappa Z manuale per UGS

Documentazione di progetto di un nuovo plugin per **UGS Platform**, destinato a rilevare manualmente la superficie di un pezzo senza sonda e a produrre una mappa importabile in AutoLeveler.

- [Specifica del comportamento](specifica-funzionale.md)
- [Roadmap e checklist di sviluppo](roadmap-sviluppo.md)

Stato: **plugin implementato e in verifica**, aggiornato il 22 settembre 2026. La versione di riferimento è UGS Platform 2.1.26; il test con grblHAL Simulator passa. Restano la prova manuale dell'interfaccia completa, l'importazione AutoLeveler verificata dal vivo e il collaudo sulla CNC reale. Vedere [stato-sviluppo.md](stato-sviluppo.md).
